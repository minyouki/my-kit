# QUESTION — 업무 담당자 대화 기록

- 내가 담당자 답변을 붙여넣고 지시하면 planner 세션이 질문과 답변을 순서대로 기록한다. 답변을 받기 전에는 `미답변`으로 표시한다.
- 답변에 따른 계획 변경은 내가 지시할 때만 `PLAN.md`에 반영한다.

| No. | 관련 README/DATA | 질문 | 답변 |
| --- | ---------------- | ---- | ---- |

관련 README/DATA: 관련된 과제 README 조항(위치와 짧은 원문) 또는 data/README 조항을 적는다. README에 근거가 없으면 `없음`으로 적는다. R-ID는 PLAN에서 부여하며, PLAN의 R 표 `근거` 열에서 `담당자(No.)`로 이 질문을 참조한다.
