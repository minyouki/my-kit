# 제출 전 최종 체크리스트

## 1. 목표

- [ ] 필수 요구사항을 모두 구현했으며, 각 요구사항의 확인 방법이 명확하다.
- [ ] 산출물의 형식, 파일명, 저장 경로가 과제 안내와 일치한다.
- [ ] 핵심 사용자 시나리오를 처음부터 끝까지 직접 실행했다.
- [ ] 주요 기능이 실제로 동작하며, 필요한 데이터는 새로고침 후에도 유지된다.

## 2. 코드

- [ ] 제공된 환경에서 소스 수정 없이 정상적으로 실행할 수 있다.
- [ ] 기능별로 코드가 구분되어 주요 처리 로직을 쉽게 찾을 수 있다.
- [ ] 외부 서비스 장애나 기능 제약이 발생해도 사용자에게 적절한 안내가 제공된다.
- [ ] 인증 정보는 실행 환경에서 관리하며, 소스·설정·Git 이력·로그에 노출되지 않는다.
- [ ] 자료 손실, 중복 처리, 권한 문제 등 주요 위험을 점검했다.
- [ ] README에 설치·실행 방법과 필요한 설정을 정리했다.

## 3. 테스트

- [ ] 주요 기능의 정상 동작을 실제 실행 결과로 확인했다.
- [ ] 빈 입력, 잘못된 값, 외부 서비스 오류, 응답 지연 등 관련 예외를 테스트했다.
- [ ] 발견한 오류를 수정한 뒤 동일한 조건에서 다시 검증했다.
- [ ] 터미널·API·브라우저 등을 이용해 결과를 직접 확인했다.
- [ ] 웹 과제라면 실제 화면을 브라우저 자동화로 캡처하고 핵심 UI 동작을 점검했다.
- [ ] 검증하지 못한 기능을 완료된 것으로 표시하지 않았다.

---

**최종 우선순위:** 필수 기능의 정상 작동 → 실행 및 검증 가능성 → 제출물 완성 → 부가 기능 개선.
